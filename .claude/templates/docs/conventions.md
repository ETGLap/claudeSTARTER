# Conventions

> How we write things here. Only what the code does not already make obvious.

## Naming

Files, directories, symbols, database objects, branches.

## Code style

Formatter and linter (they own the mechanical rules — do not restate them here). Record only
the judgment calls a tool cannot enforce.

## Git

Commit format, branch naming, PR process, review expectations.

## Testing

Where tests live, how they are named, what gets a test and what gets manual verification.

## Documentation

What must be documented, where it goes, and when — see [[architecture]] and the ADRs in
`decisions/`.
